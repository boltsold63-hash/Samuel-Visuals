Samuel Henrique Fotografia
Site oficial da marca Samuel Henrique Fotografia, de Uberlândia, Minas Gerais.
Página única, minimalista e cinematográfica, pensada para ser o link principal da bio do Instagram.
Destaques
Identidade visual preta com detalhes em prata e azul acinzentado
Layout responsivo para celular, tablet e computador
Botões de WhatsApp com mensagem pré-preenchida
Animações leves, com suporte a `prefers-reduced-motion`
HTML semântico, sem dependência de JavaScript para o conteúdo
SEO e visibilidade para IA
Dados estruturados em JSON-LD (Schema.org): negócio, serviços e FAQ
`robots.txt` liberando buscadores e rastreadores de IA
`sitemap.xml` e `llms.txt`
Meta tags Open Graph e Twitter Card
Estrutura
```
├── index.html
├── robots.txt
├── sitemap.xml
├── llms.txt
├── vercel.json
├── favicon.svg
└── og-image.png
```
Como publicar
Substitua `SEU-DOMINIO.vercel.app` pelo endereço real em `index.html`, `robots.txt`, `sitemap.xml` e `llms.txt`.
Importe o repositório em vercel.com/new. Não precisa de build.
Envie o `sitemap.xml` no Google Search Console.
